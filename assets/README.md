# Assets Directory

Static assets for the GMOD Workshop Manager project.

## Contents

### Images

**pic.jpg**
- Example/placeholder workshop thumbnail
- 512x512 pixels
- Generated by `create_workshop_image.py`
- Use as template for your own images

## Workshop Image Guidelines

### Technical Requirements

- **Format**: JPEG (.jpg)
- **Dimensions**: 512x512 pixels (recommended)
- **File Size**: Under 1 MB
- **Color Mode**: RGB

### Design Recommendations

✅ **Do:**
- Use high-quality images
- Keep text minimal and readable
- Use bright, eye-catching colors
- Show representative content
- Include your addon name/logo
- Test at thumbnail size

❌ **Don't:**
- Use low-resolution images
- Add too much text
- Use dark/muddy colors
- Mislead about content
- Violate copyrights
- Use offensive content

### Creating Workshop Images

**Method 1: Generate Placeholder**
```bash
cd scripts
python create_workshop_image.py
```

**Method 2: From Screenshot**
1. Take in-game screenshot (F12 in Steam)
2. Open in image editor
3. Crop to square (512x512)
4. Save as pic.jpg

**Method 3: Design Custom**
1. Use Photoshop/GIMP/Paint.NET
2. Create 512x512 canvas
3. Design your image
4. Export as JPEG
